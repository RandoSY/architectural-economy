# H2 stage 2 — actual genomic inputs joined

## One next action
Unzip this package on a network-enabled Linux x86-64 computer (or Ubuntu on Windows/WSL). In that folder run `bash Get_Conservation.sh`. Upload `conservation_hg19.tsv` after success. The shell script downloads the official UCSC utility, which retrieves the relevant ranges of a remote BigWig rather than requiring a manual full-genome download. If remote access fails, download the hg19 BigWig separately and run `bash Get_Conservation.sh /path/to/hg19.100way.phyloP100way.bw`. Script syntax checked; network execution not tested in this environment. The six output columns are interval identifier, length, covered bases, sum, mean including missing as zero, mean over covered bases. Use the sixth column and coverage; never substitute zero for missing.

## Data and limitations
- Replogle et al., Cell 2022, DOI 10.1016/j.cell.2022.05.013; supplement https://doi.org/10.25452/figshare.plus.21632564. The provided annotated Figure 2D profiles are a selected subset (minimum reported DE count 51); do not interpret as a genome-wide representative sample. Reach here is the published count of significant expression responses, not proof of direct or higher-order regulatory causation. Full p-value matrix is available in the original archive for a subsequent unselected analysis. Match by gene symbol with ambiguous profiles removed; verify mappings against versioned gene annotations later.
- Nasser et al., Nature 2021, DOI 10.1038/s41586-021-03446-x; https://www.engreitzlab.org/resources/. Uploaded ABC atlas is thresholded at score >=0.015; the extracted subset is K562-Roadmap, hg19 (GRCh37). Primary target is highest score among eligible distal links, with exact ties excluded; intergenic class only and >=2kb from assigned TSS. Independent exon and promoter overlap exclusions still required. R_buffering_thresholded is log1p of the raw ABC numerator sum of other retained distal links for the same gene, including genic candidates; this is a thresholded proxy only, not functional redundancy. ABC target expression absent in this biosample. No data on activity breadth, LOEUF, GC/local neutral rate or other independent covariates in this table yet.
- UCSC hg19 100-vertebrate phyloP (https://hgdownload.soe.ucsc.edu/goldenPath/hg19/phyloP100way/), distinct from the manuscript's planned Zoonomia hg38 endpoint. Use as exploratory initial outcome, then reproduce with Zoonomia after coordinate conversion. No conservation data have been observed here. No H2 effect or significance is claimed.
- Source extraction script and cohort preparation script are included. Python dependencies: pandas, numpy. `cohort_summary.json` records exact counts.
